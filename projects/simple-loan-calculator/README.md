# Simple Loan Calculator

A simple command-line tool to calculate loan payments.

## Usage

Run `python main.py` and follow the prompts to enter the loan amount, interest rate, and loan term.

The program will then calculate and display the monthly payment.

## Example

```
Loan Amount: 10000
Interest Rate (annual %): 5
Loan Term (years): 5

Monthly Payment: $188.71
```
