# Simple Age Calculator

A simple command-line tool to calculate age based on birthdate and current date.

## Usage

Run `python main.py` and follow the prompts to enter the birthdate and current date.
The program will then calculate and display the age in years.

## Example

```
Birth Year: 1990
Birth Month: 5
Birth Day: 15
Current Year: 2024
Current Month: 10
Current Day: 27

Age: 34 years
```
